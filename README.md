# ⚡ CSP Video Studio

A sleek, modern Windows desktop application for downloading high-quality video and audio streams. Built with Electron and powered by `yt-dlp`, this tool provides a fast, ad-free, and straightforward way to save media directly to your local drive.

## 🚀 Features

- **Multiple Resolutions:** Choose from 8K (2160p), 1080p, or 720p.
- **Audio Only:** Direct extraction to MP3.
- **Metadata Preview:** Inspect links to see the video thumbnail, title, and channel before downloading.
- **Custom Directory:** Choose exactly where your files are saved.
- **Dark Mode UI:** A clean, distraction-free interface built for desktop.
- **Portable Backend:** The powerful `yt-dlp` engine is bundled directly into the app.

## 📥 Installation

You do not need to compile this code to use the app! 

1. Head over to the [Releases](../../releases) tab.
2. Download the latest `CSP Video Studio Setup.exe`.
3. Run the installer and launch the app.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend/Framework:** Electron (Node.js)
- **Download Engine:** yt-dlp
- **Packaging:** electron-builder
